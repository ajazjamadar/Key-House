Good to know

A few practical answers.

Does Keyhouse provide API keys?

No. The catalog contains public API information only. You add and manage credentials you already own.

Where are my credentials stored?

Credentials are stored locally in an encrypted file. The encryption key is supplied through your environment configuration and is not included in the catalog or client bundle.

Is this a hosted team vault?

No. Keyhouse is designed for a single-user local deployment. Keep it on your local host and do not expose its port publicly.

Can I see a secret without revealing it?

Saved values are masked by default. The dashboard provides intentional Reveal and Copy actions for the credential you choose.
